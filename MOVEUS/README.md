# MOVE:US STEP 17 — 휴식 건너뛰기 (무음)

## 가장 안전한 적용 (추천)

MOVE-US-step17-rest-skip-UPDATE.zip 안의 `sketch.js` 한 파일만 기존 MOVE:US 프로젝트의 파일과 교체하세요.

1. 현재 MOVE:US 폴더를 백업합니다.
2. ZIP 압축 해제 → `sketch.js` 복사.
3. 현재 프로젝트의 `sketch.js`만 덮어쓰기.
4. Live Server 화면에서 `Ctrl + Shift + R` 새로고침.

이 ZIP에는 `firebase-config.js`, `family-cloud.js`, `index.html`, `style.css`가 들어 있지 않습니다. 기존 Firebase 계정 설정, ME/MOM 진행도 바와 각종 화면을 유지합니다.

## 새 기능

- 푸시업 1세트 끝나면 60초 시계와 `▶ 휴식 건너뛰기` 버튼 표시
- 스탠딩 힙 어브덕션 첫 좌우 40회 뒤 45초 시계와 버튼 표시
- 월 엔젤 세트 사이 60초 시계와 버튼 표시
- 버튼을 누르면 *현재 휴식만* 종료해 다음 세트로 진행, 운동 횟수 건너뛰기는 불가능
- 버튼을 누르지 않으면 기존처럼 남은 시간 끝에 자동 진행
- 휴식 중 저장된 Firebase 진행도도 다음 세트 상태로 저장 요청
- 음성 안내 및 효과음 없음. 초침 중심/360도 회전 수정 그대로 유지

## 전체 프로젝트 ZIP

전체본은 이전에 전달한 Firebase 설정 복구 버전을 기초로 만들었지만, 현재 사용자가 직접 수정한 개별 디자인과 다를 수 있습니다. 전체 ZIP을 현재 프로젝트에 통째로 덮어쓰기보다는 새 폴더에서 시험하세요.

참고: Firebase 웹 클라이언트 설정값 및 사용자 UID가 포함되어 있지만 비밀번호, 관리자 비밀키는 포함되어 있지 않습니다.
