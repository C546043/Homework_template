# MOVE:US — 무릎 대고 푸시업 학습 테스트

현재 잘 실행되는 MOVE:US 13단계 게임 파일을 **수정하지 않는** 독립 실험 버전입니다.
이전 SQUAT LAB에서 검증된 `p5.js + ml5.bodyPose() + ml5.neuralNetwork()` 흐름을 재사용합니다.

## 실행
1. VS Code에서 이 폴더 전체를 엽니다.
2. `index.html`을 우클릭 → **Open with Live Server**.
3. Chrome에서 카메라를 허용하고 `① 카메라 시작`을 누릅니다.
4. 카메라 화면에 어깨·팔꿈치·손목 관절점이 보이는지 확인합니다. 무릎을 바닥에 대고, 카메라를 너무 높게 두지 않으며 측면이나 약 30~45도 사선에서 팔 전체가 잘 보이도록 합니다. 영상은 원본 비율을 유지하며 잘리지 않습니다.
5. `▶ 자동 학습 시작`을 **한 번** 누릅니다. 팔을 편 자세(UP)와 굽힌 자세(DOWN)를 안내대로 `UP → DOWN → UP → DOWN → UP → DOWN` 순서로 유지하면 자세당 8개씩 3번, 24개씩 총 48개 샘플을 모읍니다. 각 수집은 자세가 확인되고 카운트다운이 끝난 뒤 약 1.2초입니다.
6. 자동 학습이 끝나면 측정이 시작됩니다. `UP → DOWN → UP`을 완료할 때만 카운트가 +1 됩니다.
7. 10회 완료 시 일시정지되므로 충분히 휴식한 뒤 **쉬고 다음 세트 시작**을 클릭하세요. 다시 10회 하면 총 20회 완료입니다. 횟수는 초기화되지 않습니다.
8. 학습과 측정이 잘 되면 **학습 데이터 JSON 저장**을 눌러 만든 `MOVE-US-knee-pushup-training-data.json` 파일을 공유해 주세요. 이후 본게임의 벽 부수기와 연결합니다.

## 중요한 차이
- 무릎 푸시업은 스쿼트 데이터로 학습할 수 없습니다. 새로운 자세 특성을 **직접 수집**합니다.
- 핵심 관절은 한쪽 팔의 **어깨·팔꿈치·손목**입니다. 골반·무릎은 보조 진단에 표시하지만, 필수 판정 기준이 아니어서 측면에서 팔만 잘 보여도 인식 테스트를 할 수 있습니다.
- 학습하는 8개 특징값: 팔꿈치 각도, 어깨/팔꿈치/손목 세로 위치, 어깨-손목 상대 높이, 어깨-팔꿈치 상대 높이, 어깨-손목 및 팔꿈치-손목 가로 거리.
- 자세 분류에서 같은 상태를 3번 연속 확인해야 인정합니다. `UP → DOWN → UP` 순서가 완성돼야 1회를 셉니다.
- 현재 카메라 동작 감지는 바닥에 무릎을 실제로 댔는지를 증명하지 않으며, 올바른 자세나 안전성을 인증하는 기술이 아닙니다. 통증이 있다면 중단하세요.
- 학습 데이터는 브라우저 메모리에서만 보관하며 영구저장/서버 저장을 하지 않습니다. 새로고침하면 초기화됩니다. JSON을 수동 저장했다면 나중에 다시 불러와서 학습할 수 있습니다.
- `ml5` 및 `p5` 라이브러리를 처음 로딩할 때 인터넷 연결이 필요합니다.

## 인식 안 될 때
- 팔꿈치 또는 손목에 0% 같은 낮은 신뢰도가 보인다면 카메라 높이를 낮추거나 몸을 약간 돌려 팔이 겹치지 않도록 합니다.
- UP 자세가 계속 감지되지 않는다면 팔꿈치를 편 상태가 카메라에 보이는지 확인합니다. DOWN 자세 수집에 들어간 뒤에는 UP 기준 팔꿈치 각도에서 **23도 이상 굽혀지는 동작**을 기다립니다(초기 실험 기준; 필요 시 사용자 자세 데이터에 따라 조정).
- 데이터가 잘못 수집됐다면 `자동 학습 시작`을 다시 눌러 새로 수집하세요.

## 주요 파일
- `index.html` — 인터페이스, p5.js 및 ml5.js 연결
- `style.css` — 영상 전체 비율 유지, 레트로 스타일 UI
- `sketch.js` — BodyPose, 특징 추출, 직접 학습, 자동 카운트, 10×2세트
