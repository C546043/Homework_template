# MOVE:US SQUAT LAB — 자동 음성 학습 버전

이 프로젝트는 기존 MOVE:US 본게임(버전 11)과 분리되어 있습니다. 본게임 파일을 덮어쓰지 마세요.

## 1. 실행

1. `MOVE-US-SQUAT-C-FIX.zip`을 압축 해제합니다.
2. VS Code에서 `MOVE-US-SQUAT-C-AUTO` 폴더를 열고 `index.html`을 Live Server로 실행합니다.
3. Chrome에서 `카메라 시작`을 누르고 웹캠 권한을 허용합니다.
4. PC 소리를 켜고 Chrome 탭이 음소거되어 있지 않은지 확인합니다. `한국어 음성 + 알림음` 체크를 켜둡니다.
5. `자동 학습 시작 (원터치)`을 눌러 주세요. 이 버튼은 카메라에 전신이 아직 보이지 않아도 작동합니다.
6. 카메라에서 충분히 떨어져 전신(어깨·골반·무릎·발목)이 나오도록 섭니다. 화면을 보지 않아도 음성으로 다음 동작을 알려줍니다.

## 2. 자동 학습 순서

자동 학습은 아래 네 블록을 차례대로 실행합니다. 각 블록에서는 유효한 신체 자세가 확인되면 준비 안내와 약 3초의 카운트다운 후 12개 샘플(약 2초)을 수집합니다.

1. 선 자세 12개
2. 앉은 자세 12개
3. 선 자세 12개
4. 앉은 자세 12개

최종적으로 선 자세 24개, 앉은 자세 24개를 모아서 신경망을 자동 학습합니다. 학습 완료 후에는 별도의 버튼을 누르지 않아도 측정이 시작됩니다.

앉은 자세는 이미 수집한 선 자세와 비교해 엉덩이가 충분히 내려왔을 때 수집합니다. 카메라가 자세를 인식하지 못하면 수집을 기다립니다. 수집 중 자세가 1초 이상 사라지면 현재 12개 블록을 다시 시작하며, 이전에 완료한 블록의 샘플은 유지합니다.

## 3. 스쿼트 카운트

선 자세 → 앉은 자세 → 다시 선 자세의 세 단계를 안정적으로 감지하면 `1회`로 측정합니다. 횟수가 증가하면 음성/알림음으로 알려줍니다. 스쿼트 자세를 완벽하게 평가하는 기능은 아닙니다.

## 4. 수동 학습 버튼도 유지

`선 자세 12개 수집 예약`, `앉은 자세 12개 수집 예약`을 누른 후 멀리 이동해도 됩니다. 올바른 자세가 감지될 때까지 기다린 후 자동으로 기록합니다. 두 자세를 각각 최소 24개씩 모은 후 `수집한 자세로 학습하기`, `스쿼트 측정 시작` 버튼을 사용해도 됩니다.

## 5. 음성이 들리지 않을 때

- 브라우저 탭이나 Windows 소리가 음소거되어 있는지 확인합니다.
- 안내 음성이 기기 환경에서 지원되지 않을 수 있습니다. 이 경우 가능한 환경에서는 짧은 알림음이 울립니다.
- `한국어 음성 + 알림음`을 껐다 켜면 음성 테스트가 실행됩니다.
- 인식이 불안정하다면 조명이 밝은 위치에서 카메라를 고정하고, 신체가 프레임에서 잘리지 않는지 확인합니다.

## 6. 데이터 및 안전

서버, Firebase, localStorage, sessionStorage에 영상이나 학습 데이터를 업로드/저장하지 않습니다. 새로고침하면 학습 내용과 횟수가 초기화됩니다. 필요하면 `학습 데이터 JSON 저장` 기능으로 관절 특징값만 컴퓨터에 보관할 수 있습니다.

카메라 기반 판정은 실제 운동 자세의 정확성이나 안전성을 보장하지 않습니다. 무리하게 오래 앉은 자세를 유지하지 말고 불편하거나 아프면 중단하세요.


## 주요 관절 인식 수정 (진단 버전)
- 이전 버전은 어깨·골반·무릎·발목이 한쪽에서 모두 43% 이상이어야 학습했습니다. 화면에 전신이 나와도 발목 신뢰도가 낮으면 학습을 못 했습니다.
- 이 버전은 어깨·골반·무릎이 한쪽에서 각각 25% 이상이면 자세 데이터를 수집합니다. 발목은 참고 표시만 합니다.
- BODY CHECK 아래에 좌/우 주요 관절 신뢰도가 표시돼 어디가 검출되지 않는지 알 수 있습니다.
- `정확도 우선 (Thunder)`가 기본 선택입니다. 느리거나 인식이 안 되면 카메라를 끄고 `속도 우선 (Lightning)`으로 바꾼 뒤 다시 켜 보세요.
- 학습 특징값 정의를 변경했으므로 과거 JSON과 호환되지 않습니다. 현재 실험은 별도 폴더로 실행하세요.
- 카메라 영상은 전체 비율로 표시하고, 검출 관절 좌표도 같은 확대 비율로 그립니다.
- 여전히 이미지에서 실제 위치가 틀리거나 인식이 안 되면 BODY CHECK의 자세 진단 문구와 카메라 표시 화면을 공유해 주세요.
- 실내에서 안전하게 동작하고 허리/무릎에 통증이 있다면 테스트를 중단하세요. 자동 학습 모델은 안전하거나 정확한 운동 동작을 보증하지 않습니다.

- 기존 `await ml5.bodyPose(...)` 대신 `bodyPose = ml5.bodyPose(...)` → `await bodyPose.ready` → `bodyPose.detectStart(...)` 순서로 변경했습니다.
- `BodyPose 모델 다운로드 및 초기화 중…` 상태에서는 카메라가 보이더라도 아직 관절 검출을 시작하지 않습니다.
- 모델 로딩 실패 시 경고를 표시하므로 Chrome 개발자 도구 Console의 `BodyPose camera error` 내용을 확인해 주세요.
- `favicon.ico` 404와 WebGPU `powerPreference` 경고는 이 문제의 핵심 원인이 아닙니다.
- 변경된 파일은 `sketch.js`이고, 다른 게임 파일 및 학습 기능은 유지합니다.
- 현재 환경에서 실제 웹캠으로 검증하지 못했으므로 첫 실행 후 본인 PC에서 확인해야 합니다.
